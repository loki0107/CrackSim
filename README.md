# CrackSim - Password Security Analyst 🔓

## Overview
CrackSim is a cybersecurity simulation tool that demonstrates the mechanics of **Dictionary Attacks** (Brute Force) on SHA-256 hashes. It is designed for educational purposes to highlight the importance of strong passwords.

## Features
- **Real-time Hashing:** Verifies SHA-256 hashes instantly.
- **Attack Simulation:** Visualizes the speed of dictionary attacks.
- **Custom Wordlists:** Supports importing external dictionary files.

## How to Run
1. Install dependencies: `pip install -r requirements.txt`
2. Run the app: `python cracker_app.py`# CrackSim
